# AI駆動日記アプリ 要件定義書

## 1. プロジェクト概要

### 1.1 アプリケーション名
AI駆動日記（AI-Driven Diary）

### 1.2 目的
ユーザーが日々の生活を振り返り、AIによる洞察に満ちたフィードバックを受け取ることで、自己理解を深め、感情の傾向を視覚化できる日記アプリケーション。

### 1.3 対象ユーザー
- 日記を書く習慣を身につけたい人
- 自己理解を深めたい人
- 感情の変化を客観的に把握したい人
- AIからのフィードバックを通じて新しい気づきを得たい人

## 2. 機能要件

### 2.1 認証機能
- **FR-001**: ユーザーはメールアドレスとパスワードでアカウント作成できる
- **FR-002**: ユーザーはメールアドレスとパスワードでログインできる
- **FR-003**: ユーザーはGoogleアカウントでログインできる
- **FR-004**: ユーザーはパスワードリセット機能を利用できる
- **FR-005**: ユーザーはログアウトできる
- **FR-006**: 認証状態は自動的に管理され、リロード後も維持される

### 2.2 日記機能
- **FR-007**: ユーザーは新しい日記エントリーを作成できる
- **FR-008**: ユーザーは日記の内容をテキストエリアに入力できる
- **FR-009**: ユーザーは日記の日付を設定できる
- **FR-010**: ユーザーはタグをカンマ区切りで追加できる
- **FR-011**: ユーザーは日記エントリーを削除できる
- **FR-012**: 日記エントリーは日付順（新しい順）で表示される
- **FR-013**: ユーザーは日記エントリーの一覧から特定のエントリーを選択して表示できる

### 2.3 AIフィードバック機能
- **FR-014**: 新しい日記エントリー保存時に自動的にAIフィードバックが生成される
- **FR-015**: AIフィードバックはGemini APIを使用して生成される
- **FR-016**: AIは猫又おかゆのキャラクターとして親しみやすいトーンでフィードバックを提供する
- **FR-017**: AIフィードバックは感情分析、共感・励まし、気づき・提案を含む
- **FR-018**: ユーザーは既存エントリーに対して新しいAIフィードバックを生成できる

### 2.4 gratitude jar 機能
- **FR-019**: ユーザーは感謝の気持ちを記録できる
- **FR-020**: 感謝エントリーは作成者（ユーザー/パートナー）を区別して表示される
- **FR-021**: 感謝エントリーはカード形式で表示される
- **FR-022**: 感謝エントリーは日付と共に保存される

### 2.5 統計・分析機能
- **FR-023**: ユーザーは感情の分布を円グラフで確認できる
- **FR-024**: ユーザーは週間のエントリー頻度を棒グラフで確認できる
- **FR-025**: AIによる週間サマリーが表示される
- **FR-026**: 統計データは過去30日間および過去7日間を対象とする

### 2.6 データエクスポート・インポート機能
- **FR-027**: ユーザーは指定した期間の日記データをJSON形式でエクスポートできる
- **FR-028**: ユーザーはGoogleドライブに日記データをバックアップできる
- **FR-029**: ユーザーはGoogleドライブから日記データをインポートできる
- **FR-030**: 自動バックアップ機能を有効/無効に設定できる
- **FR-031**: 週1回の自動バックアップが実行される（有効時）

### 2.7 設定機能
- **FR-032**: ユーザーはGoogleドライブの接続設定を管理できる
- **FR-033**: ユーザーはGoogle API認証情報を設定できる
- **FR-034**: ユーザーは自動バックアップの有効/無効を切り替えできる
- **FR-035**: ユーザーはバックアップの接続テストを実行できる

## 3. 非機能要件

### 3.1 パフォーマンス要件
- **NFR-001**: アプリケーションの初期読み込み時間に制限は設けない
- **NFR-002**: 日記エントリーの保存時間に制限は設けない
- **NFR-003**: AIフィードバック生成に制限は設けない
- **NFR-004**: AIフィードバック生成の文字数は200文字を目安とする
- **NFR-005**: AIフィードバック生成のコストは無料枠に収まる範囲内とする


### 3.2 セキュリティ要件
- **NFR-006**: ユーザー認証はFirebase Authenticationを使用する
- **NFR-007**: 日記データはFirestoreに暗号化して保存される
- **NFR-008**: APIキーは環境変数で管理される
- **NFR-009**: Google API認証はOAuth 2.0を使用する

### 3.3 可用性要件
- **NFR-010**: アプリケーションの可用性に特に制限は設けない

### 3.4 互換性要件
- **NFR-011**: モダンブラウザ（Chrome、Safari）をサポート
- **NFR-012**: レスポンシブデザインでモバイルデバイスに対応
- **NFR-013**: ダークモード/ライトモードをサポート

### 3.5 保守性要件
- **NFR-014**: TypeScriptを使用した型安全な実装
- **NFR-015**: コンポーネントベースのReactアーキテクチャ
- **NFR-016**: 環境変数による設定管理


## 4. 技術仕様

### 4.1 フロントエンド
- **React 19.1.1**: UIライブラリ
- **TypeScript**: 型安全な開発
- **Vite**: ビルドツール
- **Tailwind CSS**: スタイリング（推定）

### 4.2 バックエンド・サービス
- **Firebase Authentication**: ユーザー認証
- **Firestore**: データベース
- **Gemini API**: AIフィードバック生成
- **Google Drive API**: データバックアップ
- **Google Sheets API**: スプレッドシート形式でのバックアップ

### 4.3 外部ライブラリ
- **react-markdown**: Markdownレンダリング
- **recharts**: グラフ表示
- **remark-gfm**: GitHub Flavored Markdown対応

## 5. データモデル

### 5.1 DiaryEntry
```typescript
interface DiaryEntry {
    id: string;           // エントリーID
    userId: string;       // ユーザーID
    date: string;         // 日付（ISO形式）
    content: string;      // 日記内容
    tags: string[];       // タグ配列
    emotion?: string;     // 感情（オプション）
    location?: string;    // 場所（オプション）
    aiFeedback?: AIFeedback; // AIフィードバック
}
```

### 5.2 AIFeedback
```typescript
interface AIFeedback {
    id: string;           // フィードバックID
    content: string;      // フィードバック内容
    generatedAt: string;  // 生成日時
    tone: 'insightful' | 'supportive' | 'curious'; // トーン
}
```

### 5.3 User
```typescript
interface User {
    id: string;           // ユーザーID（Firebase UID）
    email: string;        // メールアドレス
    name?: string | null; // 表示名
    picture?: string | null; // プロフィール画像URL
}
```
